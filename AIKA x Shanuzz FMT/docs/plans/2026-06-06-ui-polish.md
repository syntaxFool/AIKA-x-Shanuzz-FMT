# UI/UX Polish Implementation Plan

**Goal:** Full UI polish pass across all screens — login, dashboard, entry form, user management, empty/loading states. Color scheme (#F9A825 amber) stays unchanged.

**Architecture:** All changes are Flutter widget refinements — no new logic, no backend changes. Focus on tighter spacing, better visual hierarchy, subtle background containers, and improved empty states.

**Tech Stack:** Flutter Web (Material 3), existing amber theme.

---

## Task 1: Polish Login Screen

**Files:** `lib/screens/login_screen.dart`

**Changes:**
- Wrap form content in a white rounded card (`Card` with 16px border radius) for a defined container
- Wrap the app icon in a circular gradient background (amber → amber-200) to make it pop
- Slightly larger input field, more generous vertical padding (32px between icon and fields)
- Add subtle hint text below the button: "Enter your access key to sign in"

**Commit:** `git commit -m "ui: polish login screen with card layout and icon background"`

---

## Task 2: Polish Dashboard Layout

**Files:** `lib/screens/home_screen.dart`

**Changes:**
- **User info card:** reduce to a thin bar (8px padding, smaller avatar, inline row)
- **Summary card:** reduce internal padding from 20px to 16px
- **Entry list cards:** reduce horizontal margin from 16px to 12px, reduce vertical margin from 8px to 6px
- **Leading avatar in list:** smaller (24px instead of 32px), using entry index instead of reffid substring
- **Entry subtitle:** single row showing date + mode inline instead of stacked

**Commit:** `git commit -m "ui: polish dashboard with tighter spacing and compact cards"`

---

## Task 3: Polish Entry Form

**Files:** `lib/screens/entry_form_screen.dart`

**Changes:**
- Reduce vertical spacing between fields from 16px to 12px
- Amount field: use larger font (18px) when editing for better readability
- Add a subtle background tint to autocomplete field when it has content (`Colors.amber[50]`)
- Wrap form in a white card with rounded corners for consistency with login screen

**Commit:** `git commit -m "ui: polish entry form with tighter spacing and larger amount font"`

---

## Task 4: Polish User Management Screen

**Files:** `lib/screens/user_management_screen.dart`

**Changes:**
- Reduce card margins (12px horizontal, 6px vertical) and internal padding
- Add a small column header row ("Name / Email / Role") above the list
- Add a "Role" dropdown (admin/viewer) to the edit user dialog so admins can change roles without PocketBase Admin UI
- Show role as a colored chip badge in the user card (amber for admin, grey for viewer)

**Commit:** `git commit -m "ui: polish user management with role badge and role editing"`

---

## Task 5: Improve Empty & Loading States

**Files:** `lib/screens/home_screen.dart`, `lib/screens/entry_form_screen.dart`

**Changes:**
- **Empty entries:** replace plain text with centered column: faded grey icon (Icons.receipt_long, size 64), heading "No entries yet", subtitle depending on role (admin: "Tap + to add your first entry" / viewer: "Check back later")
- **Loading entries:** replace CircularProgressIndicator with 3 skeleton placeholder cards (grey containers with shimmer effect using AnimatedContainer pulse)
- **Empty search results:** show "No entries match your search" with a search icon instead of generic "No entries found"

**Commit:** `git commit -m "ui: improve empty states with illustrations and skeleton loading"`
